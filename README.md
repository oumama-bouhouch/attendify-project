# Attendify

### Smart Attendance Management System

Attendify is a mobile attendance management project combining a mobile application, biometric identification and a physical prototype.

## Features

- Login & registration
- Home interface
- Weekly planning
- User profile
- Attendance tracking
- Fingerprint-based identification
- Electronic attendance prototype

## Technologies & Components

- Flutter
- ESP32
- Raspberry Pi
- Fingerprint sensor
- OLED display
- Electronic simulation
- 3D prototyping
